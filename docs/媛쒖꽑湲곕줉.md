# 연구해듀오 프로토타입 개선 기록

매주 시나리오를 돌려 보고 발견한 문제와 보완 내용을 적어요. 이 표가 그대로 발표의 ‘발견한 문제점’과 ‘지난주 보완 내용’이 됩니다.
사이트 오른쪽 아래 **테스트 메모 → 표 형식으로 복사**를 누르면 아래 표 모양으로 복사돼요.

## v0.1 (2026-11-03): 첫 구현

**구현 범위**
- ① 연구 프로필: 역량(숙련도·근거)·관심·목표 성과·협업 조건 입력, 실제 프로필 화면 미리보기
- ② 프로젝트 개설·매칭: 필요 전문성을 ‘자리’로 등록 → 점수(100점)·추천 이유·경고 표시, 나에게 맞는 프로젝트
- ③ 요청·커피챗·그룹: 요청 → 수락 → 커피챗 → 협업 합의서 → 그룹, 실패 사유 기록, 재매칭 버튼

**이번 주에 확인해 볼 것 (예상 문제)**
- 100점 동점이 많아서 누가 더 적합한지 구분이 안 되는가?
- 같은 분야의 ‘관련 분야’ 추천이 오히려 헷갈리게 만드는가?
- 프로필 입력 항목이 많아서 학부생이 끝까지 쓰기 어려운가?
- 학부생이 ‘필요한 전문성’을 정확한 용어로 모를 때 어떻게 하나?
- 상대가 요청을 받는 쪽 화면(수락하는 입장)이 없어도 괜찮은가?
