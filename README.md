# 연구해듀오 (Research Duo) 프로토타입 v0.4

> 필요한 전문성으로 공동 연구자를 찾고 연결하는 AI 기반 연구자 매칭 서비스
> 과학기술학개론 조별 프로젝트

**v0.4 핵심 변화**
- 백엔드를 **구글 시트 → Vercel 서버 함수 + Postgres**로 이전 (속도 개선, 배포 자동화)
- **보안 강화**: 가입 시 동의, 실명 대신 **닉네임**, 프로필 **공개범위**(전체 / 적합도 높을 때만 / 비공개)
- **열람 제한**: 매칭은 적합도 임계값 이상만 기본 노출, 상세 프로필(관심 연구 소개 등)은 연결된(요청·같은 팀) 연구자에게만
- **계정 관리**: 비밀번호 변경, 닉네임 변경

## 1. 구조 (한눈에)

```
[브라우저]  →  /api/rpc (Vercel 서버 함수)  →  Postgres (Vercel 데이터베이스)
  화면            api/rpc.js + lib/            회원·프로필·프로젝트·요청·메시지·후기
```
화면과 서버가 같은 사이트라서 서버 주소를 따로 넣을 필요가 없어요(`/api/rpc` 고정).

## 2. 폴더 구조

```
index.html                 홈
core/                      공통 (config·common·data·style·team-kit)
features/                  화면: auth(로그인) / profile / matching / connect
api/rpc.js                 ★ 서버 함수 (모든 요청 처리) — Apps Script 대체
lib/actions.js             서버 로직 (회원·프로필·매칭·팀·메시지·후기)
lib/db-pg.js               Postgres 연결 (pg)
package.json / vercel.json 배포 설정 (Vercel이 자동 인식)
docs/개선기록.md           주간 발표용 기록
```

## 3. Vercel 배포 (팀장이 한 번, 약 15분)

### ① GitHub에 코드 올리기
- 기존 저장소(또는 새 저장소)에 이 폴더 **안의 내용 전부**를 올려요. (지난번과 동일: Add file → Upload files)

### ② Vercel 가입 + 저장소 연결
1. **vercel.com** 접속 → **Sign Up** → **Continue with GitHub** (깃허브 계정으로 로그인)
2. **Add New… → Project** → 우리 저장소 **Import**
3. 설정은 **그대로 두고 Deploy** (정적 사이트 + `api/`를 자동 인식, 빌드 설정 불필요)
4. 1~2분 뒤 `프로젝트이름.vercel.app` 주소가 생겨요. **아직 로그인하면 오류가 나요 → ③에서 DB를 붙여야 해요.**

### ③ 데이터베이스(Postgres) 붙이기
1. Vercel 프로젝트 화면 위 **Storage** 탭 → **Create Database** → **Postgres** 선택 → 지역은 가까운 곳(예: Singapore) → Create
2. 생성되면 **Connect to Project**로 우리 프로젝트에 연결해요. (`POSTGRES_URL` 환경변수가 자동으로 들어가요)
3. 위 **Deployments** 탭 → 최신 배포 오른쪽 **⋯ → Redeploy** (환경변수를 반영하려고 한 번 다시 배포)

### ④ 확인
- `프로젝트이름.vercel.app/api/rpc` 를 주소창에 열어 `{"ok":true,"service":"researchduo","version":"v0.4"}` 가 보이면 서버 정상.
- 사이트에서 **회원가입 → 프로필 저장**이 되면 완료. (테이블은 첫 요청 때 자동 생성돼요)

### ⑤ 그 다음부터
- GitHub에 파일을 올리면 Vercel이 **자동으로 다시 배포**해요. (zip 수동 업로드 끝!)
- 팀원들은 각자 **새로 회원가입**하면 돼요. (구글 시트 데이터는 옮기지 않아요 — 깨끗하게 새로 시작)

## 4. 로컬에서 고치고 싶을 때
- 화면만 바꾸는 거라면 기존처럼 파일을 GitHub에 올리면 Vercel이 자동 배포해요.
- 서버 로직은 `lib/actions.js`, DB 연결은 `lib/db-pg.js` 예요.

## 5. 주의
- 프로토타입이라 보안이 약해요. **실제로 쓰는 비밀번호는 쓰지 마세요.** 비밀번호는 복원 불가능하게 암호화돼 저장돼요.
- 공개범위 **비공개**인 프로필은 매칭·검색에서 빠지고, 상세 소개는 연결된 연구자에게만 보여요.

## 6. 매주 발표 흐름
1. 지난주 피드백 → 반영한 것
2. 이번 주 범위
3. **사용자 입장에서 흐름 시연**: 가입 → 프로필 → 매칭 → 요청(기여 의향) → 지원자 비교 → 커피챗 → 팀 공간 → 완료·후기
4. 발견한 문제점 (오른쪽 아래 테스트 메모 → 표 형식 복사)
5. 다음 계획
