# 연구해듀오 프로토타입 개선 기록

매주 써보고 발견한 문제와 보완 내용을 적어요. 이 표가 그대로 발표의 ‘발견한 문제점’과 ‘지난주 보완 내용’이 됩니다.
사이트 오른쪽 아래 **테스트 메모 → 표 형식으로 복사**를 누르면 아래 표 모양으로 복사돼요.

## v0.2 (2026-11-10): 피드백 반영

**받은 피드백**
- 데이터는 스프레드시트(또는 Vercel)로 저장해서 다른 사람 컴퓨터에서도 보이게
- 가상의 학생 18명보다 팀원 6명의 실제 프로필로
- 매칭 카테고리를 1인 1개씩 골라 총 6개로 시작 → 잘 되면 늘리기

**반영한 내용**
- 로그인·회원가입 추가, 프로필·요청을 구글 스프레드시트(Apps Script)에 저장
- 더미 연구자 삭제 → 팀원 가입 후 실제 프로필로 매칭
- 매칭 카테고리 6개: ① 관심 주제 ② 연구 역량 ③ 경험 ④ 학과·전공 ⑤ 목표 성과 ⑥ 협업 조건 (카테고리마다 파일 분리)
- v0.1 문제 보완: 연구 주제 유사성 반영(①), 목표 성과 단계화(⑤), 중요 카테고리 2배 반영 기능
- 받은 요청함: 상대가 직접 수락·거절 (v0.1의 시뮬레이션 버튼 제거)

**이번 주에 확인해 볼 것**
- 팀원 6명끼리 매칭했을 때 결과가 직관과 맞는가? (“이 사람이 왜 1위지?”)
- 카테고리별 규칙(점수 배분)이 담당자가 의도한 대로 나오는가?
- 프로필 입력 항목이 많아서 귀찮지 않은가?
- 응답이 느리지 않은가? (스프레드시트 서버라 1~3초 걸림)

## v0.1 (2026-11-03): 첫 구현
- 핵심 기능 3개 모듈화, 더미 연구자 18명, 시나리오 테스트 모드
